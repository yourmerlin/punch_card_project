# ascii_papertape_project
trying to create a physical (modern) punch tape machine

why?
people should have ownership of their data, things like SD cards, hard drives, still need a computer to function. 

notes:
> maybe start off making a ascii punch tape program
> so when users type in a text box -> each letter gets converted to their proper ascii form
> m = 100 1101 ; e = 100 0101 ; r = 101 0010 ; l = 100 1100 ; i = 100 1001 ; n = 100 1110
> each row is one letter, it will have 9 columns in the row (8 data holes + 1 sprocket hole)
> it will turn each letter into binary -> 1 = hole, 0 = no hole
>
